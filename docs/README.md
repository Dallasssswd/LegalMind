# LegalMind Web (GitHub Pages)

Open [LegalMind Web](https://dallasssswd.github.io/LegalMind/) and play immediately. No setup, gateway, account, or API key is required.

This browser game includes built-in fictional legal cases, scripted courtroom witnesses, practice checklist feedback, career XP, case archives, and free browser text-to-speech where available.

**This edition does not use live AI.** Legal grading is a simple practice heuristic, not expert assessment or legal advice. The separately installed Windows and local Flask versions still support OpenAI API features.

GitHub Pages publishes this folder from branch `main`, folder `/docs`. Progress saves in the browser's localStorage; it does not synchronize across devices or with Windows, and can disappear if site data is cleared. Mobile browsers may require tapping Replay Audio to enable speech.
